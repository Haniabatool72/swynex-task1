# SWYNEX Backend Internship — Task 1

## Project Overview
A simple Node.js and Express backend server with a health-check endpoint.

## Technologies Used
- Node.js
- Express.js
- dotenv

## Features
- Express server setup
- Environment variable configuration
- Health-check API endpoint

## API Endpoint
**GET** `/health`

Example response:
```json
{
  "status": "OK",
  "message": "SWYNEX backend is running successfully"
}
```

## How to Run
1. Install dependencies:
   `npm install`
2. Start the server:
   `npm start`
3. Open `http://localhost:3000/health` in your browser.
